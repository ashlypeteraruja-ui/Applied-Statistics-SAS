# Applied-Statistics-SAS

MSc coursework demonstrating the application of statistical analysis techniques using SAS.

## Analyses Included

### 1. UK Weather Data – Multivariate Regression
Analysis of the relationship between rainfall, minimum temperature, sunshine hours, and UK weather stations.

Methods included:
- Multivariate linear regression
- Square-root transformation
- Correlation analysis
- Outlier investigation
- VIF and multicollinearity analysis
- Residual diagnostics
- Durbin-Watson test

### 2. Market Factor Analysis – PCA
Principal Component Analysis was used to identify underlying factors influencing consumer behaviour and household characteristics.

Methods included:
- Eigenvalue analysis
- Scree plot
- Factor loadings
- Varimax rotation
- Factor scores

### 3. Employee Satisfaction – Cluster Analysis
K-means clustering was used to identify groups of employees based on satisfaction, workload, salary, and other characteristics.

Methods included:
- K-means clustering
- Cluster evaluation
- Pseudo F-statistic
- Pseudo t-squared
- Cluster profiling
- Scatter plot visualisation
